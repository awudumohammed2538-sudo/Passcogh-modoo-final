# PASSCOGH-MODOO FINAL MASTER BUILD

Creator: Awudu Mohammed Modoo Ayariga

## What this build covers
- Touch-first JHS and SHS navigation
- Current NaCCA curriculum index import
- Original PASSCOGH lesson framework: simple explanations, funny/familiar mnemonics, diagrams, worked examples, step-by-step problem solving, practice, answers, practicals and quizzes
- WASSCE course/future finder
- University/college/technical university/college/institute categories
- GTEC-aware accreditation checks
- Skills Academy
- 15-minute safe study-break ad slot
- Server-side curriculum download/import so the learner's phone does not download the source PDFs

## Deployment
Render Build Command:
npm install && npm run sync

Render Start Command:
npm start

## IMPORTANT
The sync script imports the current official NaCCA curriculum PDF links and extracts their structural headings. It does not claim that copied official PDF text is original PASSCOGH teaching content.

The official source pages are:
https://nacca.gov.gh/secondary-education-curriculum/
https://nacca.gov.gh/common-core-programme-ccp/
https://nacca.gov.gh/assessment-items-for-the-common-core-programme/
https://gtec.edu.gh/accreditation/

The ad slot is a DEMO placement. Before taking money from advertisers, connect a legitimate ad provider and configure its policy/compliance settings. The timer is 15 minutes of active study time and is suppressed while a quiz/exam mode is active.

Do not publish private student index numbers. The finder is designed around grades/interests; an index number may be used only for a verified private workflow if a secure backend is later connected.
